# Contributing To VatioBoard

Thank you for helping improve VatioBoard. This project uses a dual licensing model so the Community Edition can remain open while VatioLibre Inc. can also offer commercial licenses that support long-term maintenance.

## Contribution License

By contributing to VatioBoard, you agree that your contributions may be distributed under AGPL-3.0-or-later and may also be used, sublicensed, or commercially licensed by VatioLibre Inc. under a Contributor License Agreement or equivalent written agreement.

Non-trivial contributions require a Contributor License Agreement or equivalent written agreement that grants VatioLibre Inc. rights compatible with the project's dual licensing model. Small typo fixes and other trivial contributions may be accepted without additional paperwork at the maintainers' discretion.

A Developer Certificate of Origin sign-off alone is not sufficient for non-trivial contributions unless VatioLibre Inc. determines that the process also supports the commercial relicensing goals for the contribution.

## Contributor Process

1. Open an issue or discussion for larger changes before implementation.
2. Keep changes focused and consistent with the existing architecture.
3. Include tests or documentation updates when behavior changes.
4. Confirm that your contribution is your original work or that you have the right to submit it.
5. Complete the required CLA or equivalent agreement when requested.
6. Run the relevant validation commands before submitting.

Recommended local checks:

```bash
pnpm run lint
pnpm test
pnpm run build
```
