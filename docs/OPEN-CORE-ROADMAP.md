# Open-Core Roadmap

This roadmap documents possible future product separation. It does not implement enterprise-only code and does not change the current Community Edition feature set.

## Community Edition

VatioBoard Community Edition is intended to include the core local-first browser experience:

- core SPA platform
- VatioBoard OS app platform
- board
- speed tools
- replay
- calculator
- local-first storage
- community plugins

## Potential Commercial Features

Future commercial offerings may include:

- fleet management
- organizations
- enterprise authentication
- advanced analytics
- commercial APIs
- reporting
- white-label deployments
- OEM integrations

## Principles

- Keep Community Edition useful and coherent.
- Keep licensing clear at feature boundaries.
- Preserve third-party notices and licenses.
- Avoid adding enterprise-only code paths without explicit product and legal review.
- Document any future split before moving code.
